BLAS/LAPACK

Install Netlib, OpenBLAS, oneMKL or Accelerate from Conda packages. Select the exact implementation with blas and link Fortran projects with fpm, CMake or Meson.

Implementations

Values are case-sensitive. The action installs the exact Conda selector and fails when Conda cannot satisfy it.

Implementation Runner blas
Netlib Ubuntu, macOS, Windows except ifx netlib
OpenBLAS Ubuntu, macOS, Windows except ifx openblas
oneMKL Ubuntu, Intel macOS, Windows mkl
Accelerate macOS accelerate

On Windows, use blas: mkl with ifx.

Inputs

Input Default Value
blas none none, netlib, openblas, mkl or accelerate

Selecting blas without compiler installs BLAS/LAPACK without installing a compiler or exporting compiler variables.

Permissions

Setup reads Actions job metadata and checks out the repository by default. 

permissions:
  actions: read
  contents: read

Package environment

Package discovery and linker paths are exported automatically. No workflow environment block is required.

Scope Exported variables
All runners LIBRARY_PATH, CMAKE_LIBRARY_PATH, CMAKE_PREFIX_PATH, PKG_CONFIG_PATH
Ubuntu LD_LIBRARY_PATH
Windows LIB, INCLUDE

MKL_INTERFACE_LAYER is not set by the action. oneMKL uses its default LP64 interface unless the workflow or application selects another supported interface.

fpm

fpm is installed by default. Add link = ["lapack", "blas"] to the relevant executable or test target. 

test_fpm:
  name: ${{ matrix.os }}_${{ matrix.compiler }}_${{ matrix.blas }}_fpm
  runs-on: ${{ matrix.os }}
  strategy:
    fail-fast: false
    matrix:
      include:
      - {os: ubuntu-latest, compiler: gfortran, blas: openblas, fpm-version: ""}
  steps:
    - name: setup-fortran-conda
      uses: gha3mi/setup-fortran-conda@latest
      with:
        compiler: ${{ matrix.compiler }}
        blas: ${{ matrix.blas }}
        fpm-version: ${{ matrix.fpm-version }}

    - name: fpm BLAS/LAPACK test
      run: fpm test --compiler "${{ env.FPM_FC }}" --profile release --verbose

CMake

CMake and Ninja are installed by default. Locate the lapack and blas libraries and link both to the target. 

test_cmake:
  name: ${{ matrix.os }}_${{ matrix.compiler }}_${{ matrix.blas }}_cmake
  runs-on: ${{ matrix.os }}
  strategy:
    fail-fast: false
    matrix:
      include:
      - {os: windows-latest, compiler: flang-new, blas: mkl}
  steps:
    - name: setup-fortran-conda
      uses: gha3mi/setup-fortran-conda@latest
      with:
        compiler: ${{ matrix.compiler }}
        blas: ${{ matrix.blas }}

    - name: CMake BLAS/LAPACK test
      run: |
        cmake -S . -B build -G Ninja -DCMAKE_Fortran_COMPILER="${{ env.CMAKE_Fortran_COMPILER }}"
        cmake --build build --verbose
        ctest --test-dir build --output-on-failure --no-tests=error -VV

Meson

Meson and Ninja are installed by default. Link the target with -llapack and -lblas. 

test_meson:
  name: ${{ matrix.os }}_${{ matrix.compiler }}_${{ matrix.blas }}_meson
  runs-on: ${{ matrix.os }}
  strategy:
    fail-fast: false
    matrix:
      include:
      - {os: macos-latest, compiler: gfortran, blas: accelerate}
  steps:
    - name: setup-fortran-conda
      uses: gha3mi/setup-fortran-conda@latest
      with:
        compiler: ${{ matrix.compiler }}
        blas: ${{ matrix.blas }}

    - name: Meson BLAS/LAPACK test
      run: |
        meson setup build --buildtype release --backend=ninja
        meson compile -C build --verbose
        meson test -C build --verbose
