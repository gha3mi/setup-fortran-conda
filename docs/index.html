setup-fortran-conda

Configure supported Fortran toolchains with matching C and C++ compilers on Ubuntu, macOS and Windows. Install fpm, CMake, Ninja, Meson and pkg-config with optional MPI, BLAS/LAPACK implementations and additional Conda packages. Generate FORD or Doxygen documentation, status badges, README CI tables and dependency graphs or run Fortitude.

Quick start

The action checks out the repository by default. No separate checkout step is required. 

name: test

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    permissions:
      actions: read
      contents: read
    steps:
      - uses: gha3mi/setup-fortran-conda@latest
        with:
          compiler: gfortran

      - run: fpm test

Compiler setup includes fpm, CMake, Ninja, Meson and pkg-config.
