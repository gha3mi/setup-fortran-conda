Status badges

Collect fpm, CMake and Meson matrix-job results into separate STATUS.md files and deploy them to dedicated branches for status badges.

Inputs

Input Default Value
generate-status-fpm false Generate and deploy fpm status
generate-status-cmake false Generate and deploy CMake status
generate-status-meson false Generate and deploy Meson status

Permissions

Status generation reads workflow jobs and writes each generated STATUS.md file to its status branch. 

permissions:
  actions: read
  contents: write

Required job names

Tested job names must end in _fpm, _cmake or _meson. Each status generator selects jobs by this suffix. 

test_fpm:
  name: ${{ matrix.os }}_${{ matrix.compiler }}_fpm
  runs-on: ${{ matrix.os }}
  strategy:
    fail-fast: false
    matrix:
      include:
      - {os: ubuntu-latest, compiler: gfortran}

test_cmake:
  name: ${{ matrix.os }}_${{ matrix.compiler }}_cmake
  runs-on: ${{ matrix.os }}
  strategy:
    fail-fast: false
    matrix:
      include:
      - {os: ubuntu-latest, compiler: gfortran}

test_meson:
  name: ${{ matrix.os }}_${{ matrix.compiler }}_meson
  runs-on: ${{ matrix.os }}
  strategy:
    fail-fast: false
    matrix:
      include:
      - {os: ubuntu-latest, compiler: gfortran}

Generate badges

Each status job must need every non-MPI and MPI job selected by its suffix. 

status_fpm:
  if: ${{ always() }}
  name: Generate fpm STATUS.md
  needs: [test_fpm, test_mpi_fpm]
  runs-on: ubuntu-latest
  permissions:
    actions: read
    contents: write
  steps:
    - name: Generate fpm summary
      uses: gha3mi/setup-fortran-conda@latest
      with:
        generate-status-fpm: true
