Fortitude

Install fortitude-lint in the action environment and run Fortitude checks with configurable command-line settings.

Inputs

Input Default Value
fortitude-check false Run Fortitude
fortitude-settings --output-format github Fortitude command-line options

Usage

Enabling Fortitude installs fortitude-lint. A separate installation step is not required. 

linter_fortitude:
  name: Run Fortitude Linter
  runs-on: ubuntu-latest
  steps:
    - name: Run Fortitude Linter
      uses: gha3mi/setup-fortran-conda@latest
      with:
        fortitude-check: true
        fortitude-settings: "--output-format github"
